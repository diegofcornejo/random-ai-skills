What each coverage status means

OK
The scanner is enabled and its alerts were read. Zero alerts here means zero open alerts.
Not enabled
The scanner is turned off for this repository. On a private repository this can also mean that the paid GitHub security product (Code Security or Secret Protection) is not turned on for it. Action: enable it (this requires available license seats). No alerts are counted for it.
Not licensed
GitHub reports that the organization has no license for this feature. Action: obtain licenses (GitHub Code Security or Secret Protection) before it can be enabled. No alerts are counted for it.
No permission
The account that ran the report cannot read these alerts. It needs security-alert read access to the repository, or an owner or security manager role. Open alerts may exist that this report does not show.
Unavailable
The status could not be determined: the endpoint did not answer (an older GitHub Enterprise Server, a temporary error), or, on the organization endpoints, the account is not an org owner and GitHub answered 404 to the Dependabot status check (security managers can get that). The status is unknown and no alerts are counted for it.

Counting rules

  • Only scanners with coverage OK are counted. A repository is at zero, or reaches zero, only when all three scanners are readable; 0 open alerts with a scanner missing is listed as partial coverage. A repository without coverage is never reported as zero alerts.
  • Day delta = open alerts now minus open alerts in the previous report of the same scope.
  • An alert that disappears because its scanner coverage was lost is listed under lost coverage, not as closed.
  • When there is no previous report, the set of owners changed, or the previous snapshot cannot be read, the report is a baseline and shows no day-over-day changes.
  • Secret values are never fetched or stored (hide_secret=true). Only the secret type and its validity are shown.
  • Every number comes from snapshot.json and diff.json. Rendering the same inputs again produces the same report.
