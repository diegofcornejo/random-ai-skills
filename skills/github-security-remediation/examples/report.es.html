Qué significa cada estado de cobertura

OK
El escáner está habilitado y sus alertas se leyeron. Cero alertas aquí significa cero alertas abiertas.
No habilitado
El escáner está desactivado en este repositorio. En un repositorio privado también puede significar que el producto de seguridad de pago de GitHub (Code Security o Secret Protection) no está activado para él. Acción: habilitarlo (requiere licencias disponibles). No se cuentan alertas para él.
Sin licencia
GitHub indica que la organización no tiene licencia para esta función. Acción: adquirir licencias (GitHub Code Security o Secret Protection) antes de poder habilitarla. No se cuentan alertas para él.
Sin permiso
La cuenta que generó el informe no puede leer estas alertas. Necesita acceso de lectura a las alertas de seguridad del repositorio, o el rol de propietario o de administrador de seguridad. Puede haber alertas abiertas que este informe no muestra.
No disponible
No se pudo determinar el estado: el endpoint no respondió (un GitHub Enterprise Server antiguo, un error temporal) o, con los endpoints de organización, la cuenta no es propietaria de la organización y GitHub respondió 404 a la comprobación del estado de Dependabot (puede pasarle a un administrador de seguridad). El estado es desconocido y no se cuentan alertas para él.

Reglas de conteo

  • Solo se cuentan los escáneres con cobertura OK. Un repositorio está en cero, o llega a cero, solo si los tres escáneres son legibles; 0 alertas abiertas con algún escáner faltante se lista como cobertura parcial. Un repositorio sin cobertura nunca se informa como cero alertas.
  • Delta del día = alertas abiertas ahora menos alertas abiertas en el informe anterior del mismo alcance.
  • Una alerta que desaparece porque se perdió la cobertura de su escáner se lista como pérdida de cobertura, no como cerrada.
  • Si no hay informe anterior, cambió el conjunto de propietarios o no se puede leer el snapshot anterior, el informe es una línea base y no muestra cambios día a día.
  • Los valores de los secretos nunca se obtienen ni se guardan (hide_secret=true). Solo se muestran el tipo de secreto y su validez.
